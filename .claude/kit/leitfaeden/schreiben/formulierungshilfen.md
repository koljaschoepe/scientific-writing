# Satzbausteine

> Hilfe für Menschen, die selbst schreiben (`schreibmodus: gemeinsam` oder `ich-schreibe`).
> Nicht als Vorlage für generierten Text: Gehäuft wirken solche Bausteine floskelhaft.
> Regeln und Schwellen: `stilregeln.md`. Stand: 2026-10-01

## Quellen einführen
```
[Autor] (Jahr) argumentiert, dass...
Nach Auffassung von [Autor]...
Einer Studie von [Autor] zufolge...
[Autor] definiert [Begriff] als...
```

## Gegenüberstellung
```
Während [A] ... annimmt, zeigt [B] ...
Im Gegensatz zu [A] betont [B]...
[A] und [B] stimmen darin überein, dass...
```

## Kritische Würdigung
```
Einschränkend ist anzumerken, dass...
Der Ansatz hat Grenzen: ...
Offen bleibt, inwieweit...
```

## Methoden und Ergebnisse (Naturwissenschaft, Technik)
```
Die Proben wurden bei ... präpariert und mittels ... charakterisiert.
Zur Validierung des Modells wurde der Datensatz in ... aufgeteilt.
Die Messungen zeigen eine lineare Abhängigkeit von ...
Innerhalb der Messunsicherheit stimmen ... überein.
Die Abweichung lässt sich auf ... zurückführen.
```

## Ausblick
```
Offen bleibt, ob sich ... auf ... übertragen lässt.
Weiterführende Untersuchungen könnten ... prüfen.
```

## Lieber nicht

„Die vorliegende Arbeit befasst sich mit...“, „Im Mittelpunkt der Untersuchung steht...“,
„Vor diesem Hintergrund...“, „In diesem Zusammenhang ist festzustellen...“,
„Zusammenfassend lässt sich festhalten...“, „Es wird deutlich, dass...“. Stattdessen direkt
die Aussage.

Handlungsempfehlungen für Organisationen: `../fachprofile/wirtschaft-sozial.md`.
