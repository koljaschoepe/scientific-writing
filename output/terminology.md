# Terminologie

Zentrale Fachbegriffe und Abkürzungen. Wird von Agents automatisch erweitert.

| Begriff | Abkürzung | Definition | Eingeführt in |
|---------|-----------|------------|---------------|
| Large Language Model | LLM | Großes Sprachmodell basierend auf Transformer-Architektur | 2.1 |
| Kontextfenster | -- | Maximale Anzahl an Token, die ein LLM gleichzeitig verarbeiten kann | 2.1 |
| Token | -- | Kleinste Verarbeitungseinheit eines LLM (Wort, Teilwort oder Zeichen) | 2.1 |
| Chunking | -- | Aufteilung von Texten in kleinere, verarbeitbare Abschnitte | 2.2 |
| Retrieval-Augmented Generation | RAG | Kombination aus Informationsabruf und Textgenerierung | 2.2 |
| Lost-in-the-Middle | -- | Effekt, bei dem LLMs Informationen in der Mitte langer Kontexte schlechter verarbeiten | 2.1 |
